# turkish-i

## Repository language

- Everything that lands in this repository is English: identifiers, comments, field names, commit messages, README, issues and PRs.
- Exception, by subject: Turkish sample strings in records, reproductions and tests stay Turkish (for example `"İstanbul notları"`), and the Turkish section of the README stays.
- User-facing Turkish text outside samples lives in a separate `tr` language file.
- Push approval is per commit. Ask before every push.
